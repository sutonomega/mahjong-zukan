# 麻雀図鑑 — 設計書

## 1. 目的

麻雀を始めたばかりの人が、役や用語を一つずつ調べて理解し、覚えた項目を記録できる図鑑サイトを提供する。

単なる一覧ではなく、説明文に登場する知らない用語から、その意味へすぐ移動できることを重視する。Excel由来の情報と、後から追加した説明・表記補正は区別して管理する。

## 2. 対象ユーザーと設計方針

- 主な対象は麻雀初心者。
- 役と用語を一つの図鑑として扱い、種類やカテゴリで絞り込めるようにする。
- 項目名、読み方、説明を見つけやすい形で表示する。
- 説明中の用語をリンクにし、カーソルを合わせるかキーボードでフォーカスすると説明を表示する。
- リンクを選択した後、元の説明へ戻れるようにする。
- Excel由来データを直接書き換えず、補足項目や表示補正は別に管理する。
- PCとスマートフォンの両方で利用できるようにする。

## 3. 主な利用の流れ

1. 図鑑一覧から役・用語をカードで見る。
2. 名前や読み方などで検索し、必要に応じて種類・カテゴリを絞る。
3. 項目の詳細を開き、説明を読む。
4. 説明中の用語にカーソルを合わせて意味を確認するか、クリックして用語詳細へ移動する。
5. 「前の説明へ戻る」で元の項目に戻る。
6. 覚えた項目を記録し、図鑑の進捗を確認する。

## 4. 検索の考え方

検索結果は用途に応じて次のグループに分ける。

- **検索結果**：名前・表示名・読み方が正規化後に検索語と完全一致する項目。
- **もしかして？**：名前・表示名・読み方に検索語が含まれる項目、または3〜12文字の検索語と1文字分だけ異なる項目。
- **関連する項目**：説明文に検索語を含む項目。ただし同じ項目がタイトル候補にも該当する場合は、タイトル側のグループを優先する。

完全一致、部分一致候補、説明文一致は同じ検索でそれぞれ表示されることがある。1項目が複数グループに重複表示されることはない。

検索時はUnicode NFKC正規化、小文字化、カタカナからひらがなへの変換、空白・句読点の除去を行う。これにより読み方の表記ゆれを吸収する。

## 5. 詳細表示と用語リンク

- 詳細画面には種類、項目名、読み方、カテゴリ、説明を表示する。
- 「翻」の詳細には翻数の区分表を、萬子・筒子・索子の詳細には各1〜9の牌の読み方表を補足情報として表示する。
- 説明中に用語が見つかった場合は「用語名（読み方）」の形式でリンク表示する。項目名と読み方が同一なら読みを重ねない（例：「ドラ」）。
- 元の説明に「用語（読み方）」がすでにある場合は、一つのリンクとして扱う。重複した読みの括弧は一組にまとめる。
- 用語リンクの吹き出し、カード説明、詳細説明は同じ説明データと同じ表記整形を使う。
- 「場合」の「場」は一般語なので用語リンクにしない。
- 詳細間の戻る操作では、直前の詳細項目とスクロール位置を復元する。履歴がなければ一覧へ戻る。

## 6. 学習状態の保存

- 「覚えた」状態はブラウザの `localStorage` に保存する。
- 保存キーは `mahjong-zukan-learned`。
- 同じブラウザ・端末ではページを再読み込みしても状態が残る。
- Cookie、サーバー保存、端末間同期、ユーザーアカウントは実装していない。
- 詳細画面の選択状態や戻る履歴はメモリ上にあり、再読み込みで消える。

## 7. データ方針と現在の範囲

- Excel由来の初期データは役45件、用語228件、参考URL2件。
- 別管理の補足用語は現在3件：槓（カン）、自家（ジチャ）、他家（ターチャ）。
- Excelの各行・列の値は `src/data/mahjongData.json` に保持する。
- 表示上の漢字名、読み方、説明の補正は、明示的な表示用設定として管理する。
- 補足用語は `src/data/supplementalTerms.ts` に置き、`origin` でExcel由来項目と区別する。
- 学習STEP、難易度、関連項目の推薦、サーバー同期は未実装。

## 8. 表示・レスポンシブ

- 役と用語を同じカード一覧で表示する。
- カードには種類、カテゴリ、イラスト、項目名、読み方、説明、詳細操作を配置する。
- イラストはReact内のローカルSVGで生成し、参考URLの画像は転載しない。
- レイアウトのブレークポイントは900pxと620px。
- 翻数表と牌の読み方表は画面幅が狭い場合に横スクロールできる。

## 9. 公開

GitHub Actionsが `main` へのpushまたは手動実行でビルドし、GitHub Pagesへデプロイする。ビルド時にリポジトリ名を含むbase pathを設定する。
