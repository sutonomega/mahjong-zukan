# 学習ステップ・用語分類の監査記録

Issue #6 の確認結果と変更理由を記録します。対象は `src/data/entries.ts` の役・用語276件、`src/App.tsx` の学習ステップ、入門コースのレッスン順です。元データのカテゴリは `sourceCategory` に保持し、学習画面で使う分類だけを見直しました。

## 確認と変更

### 初級の前提語を同じ段階に揃える

基本役のレッスンで必要となる `翻牌`（term-105）、`門前`（term-137）、`聴牌`（term-187）、`立直`（term-190）を初級にしました。それぞれ「基本の役」「鳴きと門前」「ゲームの進行」へ分類しました。

### 特殊役・卓の進行に関する語を中級へ移す

最初の対局で優先度が低い一発・平和・一盃口・嶺上開花・槍槓・海底模月・河底撈魚（yaku-002、005、006、014〜017）を中級の「役と翻数」に移しました。

一荘・西風戦・北風戦・ラス前・西場・北場・本場・積み棒・一本場・開門、起家・仮東・仮親、王牌・壁牌・洗牌・多牌・少牌・花牌・嶺上牌・海底牌・河底牌も中級へ移しました。進行の細部、地域・卓ごとの扱い、特殊局面を基本の牌や局の流れと分けています。中級には「牌の追加知識」ステップを設けました。

### 同じ概念の表記を見分けやすくする

初心者向け画面では、ポン・チー・ロン・ツモ和了を一般的な日本語表記に揃えました。和了の別表記・動詞形は中級へ移し、「別表記」「動詞形」と表示して基本用語と区別しました。ロン／栄和、和り形／和了形、振り込み／放銃も表示名で関係を示し、元の項目IDと出典情報は維持しました。

監査後、初級項目には説明文が完全に重複する用語が残っていません。中級以降の同義語・表記違いは、辞典検索や原資料との対応に必要なため統合・削除せず、表示上の関係を分かるようにしています。

### 学ぶ順番

初級の「基本の組み合わせ」のあとに「アガリの基礎」を置き、その後に「基本の役」を学ぶ順序にしました。レッスンも「アガリの基本形」を「役が必要」の前に移しました。まず完成する手牌の形を理解し、その形だけではアガれず役が必要になることを学べます。
