# スマートフォン表示・アクセシビリティ確認記録

対象: [Issue #20](https://github.com/sutonomega/mahjong-zukan/issues/20)

## 確認範囲

- Chromeのローカル表示でホーム画面と独立した用語辞典画面を確認しました。
- 独立辞典でTabキーからスキップリンクに移動し、Enterキーで本文へ移動できることを確認しました。
- アクセシビリティツリーで本文へのスキップリンク、主見出し、検索ラベル、ボタン名を確認しました。
- コース、図鑑、共通教材パックの実装について、フォーカス表示、操作領域、見出し、スクロール動作をコード上で確認しました。

## 確認・修正内容

- 独立した用語辞典画面に「本文へスキップ」リンクを追加しました。
- 独立した用語辞典画面の一覧名・詳細名をページの主見出しとして扱います。
- キーボード操作時のリンクにも、見分けやすいフォーカス枠を表示します。
- スマートフォン幅では、検索欄の文字を16pxにし、コース移動・回答・絞り込みなど主要操作のタップ領域を広げます。
- OSの「視差効果を減らす」設定が有効なときは、画面移動を即時にし、装飾アニメーションを抑えます。
- 牌姿の牌は文字と代替テキストを持ち、色だけで意味を区別しません。

## 確認結果と残作業

- Chromeのローカル画面でホーム、学習コース、図鑑の主要要素が表示され、操作要素に名前があることを確認しました。
- 修正後のスマートフォン実機、Firefox、Safariでの表示・操作確認は未実施です。
- 画面幅320pxでの横スクロール、拡大表示時のレイアウト、スクリーンリーダー実機の読み上げは未確認です。
- したがって、この記録は初回確認と改善内容を示すもので、Issue #20の全完了条件を満たしたことを意味しません。残る環境確認を公開前チェックで実施します。
