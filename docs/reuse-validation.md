# 再利用性の検証

Issue #25で、麻雀以外の分野の教材を共通機能で表示できるかを植物観察の教材パックで確認しました。画面表示のためのサンプル登録はパックレジストリで行い、コース・図鑑の共通表示部品に分野固有の条件分岐を追加しない構成です。

## 構成

- `GlossaryPack` と `GlossaryEntry` は、コースを含まずに用語辞典を表現します。
- `LearningPack` は、コース、レッスン、問題、用語参照を表現します。
- `GlossaryPlayer` は図鑑パック単独で一覧、検索、説明の吹き出し、詳細表示を行います。
- `CoursePlayer` はコース単独でレッスン、問題、パック・コース単位の進捗を表示します。
- `ContentPackDemo` は、コースと図鑑を切り替え、用語参照から詳細を開く統合例です。
- `contentPackDemos` にパックを登録し、`?demoPack=botany` のように選択します。新しい教材は共通プレイヤーを変更せずレジストリへ追加します。

植物サンプルは `src/content-packs/botany/sample-pack.ts` に置き、麻雀のコンテンツ、アダプター、牌姿拡張を参照しません。

## 確認結果

| 確認項目 | 結果 |
| --- | --- |
| ビルド | `npm run build` 成功。TypeScriptの型確認とViteの本番ビルドが通りました。 |
| コース単独表示 | 植物パックのコース、2レッスン、理解度チェックが表示されました。 |
| 図鑑単独表示 | コースを表示せず、植物用語3件の一覧と検索・詳細を表示できました。 |
| 用語参照 | レッスン中の「葉脈」を選ぶと、短い説明と詳細ページが開きました。 |
| 吹き出し用語検索 | 空欄で全項目が表示され、「葉脈」と読み「ようみゃく」の検索で該当語1件が表示されました。 |
| 理解度チェック | 正答を選ぶと正解表示、理由、関連レッスンへのリンクが表示されました。 |
| 進捗保存 | 1レッスン完了後、再読み込みしても2レッスン中1件・50%の進捗と現在のレッスンが復元されました。 |
| 共通ランタイムの分野依存 | コース・図鑑プレイヤーは植物パックの型とデータを受け取り、麻雀固有の分岐なしで表示しました。 |
| 辞典単独と別ロケール | `?glossaryDemo=botany-en` でコースを読み込まず英語（`en-US`）の `GlossaryPack` と共通図鑑プレイヤーだけを表示できました。`LEAF VEIN` の検索で「Leaf vein」が見つかり、詳細へ移動できました。 |

画面確認はローカル環境のChromeで行いました。別ブラウザーやスマートフォンでは確認していません。
