# 麻雀図鑑の使い方

このガイドでは、学習コースと図鑑の基本的な使い方を説明します。学習コースと図鑑はどちらからでも利用でき、学習文中の用語から図鑑の詳しい説明を開けます。

## ホーム画面から始める

ホーム画面には、学習コースと「図鑑をひらく」があります。

- **入門編**：牌の見方やゲームの流れ、アガリと役の基本を学びます。「コースを始める」を選ぶと、学習画面が開きます。
- **初級編・中級編・上級編**：現在は「作成中」と表示しています。準備ができるまで選べません。
- **図鑑をひらく**：役や用語を検索したり、カテゴリから探したりできます。

図鑑ホームでは、画面左上の「麻雀図鑑」を選ぶと検索条件をリセットできます。学習画面から図鑑を開くときは、ヘッダーの「図鑑へ」を選びます。

## 学習コースを進める

学習画面の「レッスン」一覧から、読みたいレッスンを選べます。レッスンの最後にあるボタンで前後へ移動します。「完了して次へ」を選ぶと、そのレッスンが完了として記録され、次のレッスンへ進みます。最後のレッスンでは「コースを完了する」と表示されます。

レッスン一覧には完了状態が表示され、コースの完了数と進捗率を確認できます。完了したレッスンがある場合は、一覧の下に「進捗をリセット」が表示されます。選ぶと、このコースの完了状態が消去され、最初のレッスンから始められます。

### 学習文中の用語を調べる

下線のある用語にポインターを合わせるか、キーボードでフォーカスすると、短い説明が吹き出しで表示されます。用語を選ぶと図鑑の詳しい説明を開きます。説明画面の「前の説明へ戻る」または「図鑑一覧へ戻る」を選ぶと、元の学習画面に戻れます。

タッチ端末では、用語を選んで詳しい説明を開き、戻るボタンでレッスンに戻ってください。

### 理解度チェックに答える

レッスン一覧にある「理解度チェック」を選ぶと、問題が開きます。選択肢を選ぶと、その場で正誤と解説が表示されます。不正解の場合は正解も確認できます。「関連レッスンを復習」を選ぶと、問題に関係する説明へ戻れます。回答数と正解数は問題画面で確認できます。

回答をやり直すときは「回答をリセット」を選びます。回答内容はブラウザーに保存されません。コースのレッスン進捗とは別の情報です。

## 図鑑を使う

「図鑑をひらく」まで移動し、検索欄に記事名、役や用語の名前、読み方、説明、カテゴリなどを入力します。検索結果は「検索結果」「カテゴリ・関連語で一致」「説明文で一致」などに分けて表示されます。見つからないときは別の言葉を試すか、「条件をリセット」を選んでください。

検索欄の下にあるボタンで「すべて」「役」「用語」を切り替えたり、学習カテゴリで絞り込んだりできます。絞り込みを解除するときは「条件をリセット」を選びます。

一覧のカードでは、用語や役の名前、読み方、説明の一部を確認できます。「くわしく」または名前を選ぶと詳細画面が開きます。詳細画面では、意味、カテゴリ、読み方を確認できます。役には翻数と鳴きの情報も表示されます。説明中の下線付き用語を選ぶと、その用語の説明へ移動できます。

用語の詳細画面とレッスン画面は専用URLで開けます。画面を開いたときのURLを共有すると、同じ説明やレッスンを直接表示できます。ブラウザーの戻る・進むも利用できます。URLの形式は、用語が `?term=<用語ID>`、レッスンが `?view=course&lesson=<レッスンID>` です。

覚えた項目を記録するときは、詳細画面で「覚えた！」を選びます。記録後は「習得済み」と表示されます。もう一度選ぶと習得済みを解除できます。図鑑ホームには覚えた項目数と達成度が表示されます。

## 保存について

コースのレッスン進捗と、図鑑の習得済み項目は、利用中のブラウザー内に保存されます。再読み込み後も同じブラウザーでは続きから学べます。アカウントやサーバーへの同期はありません。ブラウザーの保存データを削除した場合や別のブラウザー・端末を使う場合、以前の進捗は引き継がれません。

理解度チェックの回答は保存されず、画面を離れると消えます。

## 不具合や説明へのフィードバック

画面下部の「不具合を報告（GitHub）」または「教材に意見を送る（GitHub）」から該当フォームを開けます。報告にはGitHubアカウントが必要です。Issueは公開されるため、個人情報や非公開の情報は記載しないでください。
